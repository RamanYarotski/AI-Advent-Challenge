# День 1. Первый запрос к LLM через API

## Задание

Написать минимальный код, который отправляет запрос в LLM через API, получает ответ и выводит его в интерфейс.

## Что показать на видео

- `.env.local` с замазанным или скрытым ключом.
- Запуск `npm run dev`.
- Вкладку `Day 1 API`.
- Ввод prompt и успешный ответ модели.

## Готово, если

- Ответ приходит через backend API.
- На экране видны текст ответа, модель, время ответа и usage tokens, если провайдер их вернул.
