# День 5. Версии моделей

## Задание

Выполнить один prompt на слабой, средней и сильной модели. Замерить время ответа, токены, стоимость и сравнить качество.

## Что показать на видео

- Вкладку `Day 5 Models`.
- Три model id.
- Один prompt.
- Таблицу с ответами, временем, токенами и стоимостью.
- Короткий вывод по качеству, скорости и ресурсоемкости.

## Готово, если

- Можно менять model id прямо в интерфейсе.
- Стоимость берется из провайдера или считается по вручную введенным ценам за 1M input/output tokens.
