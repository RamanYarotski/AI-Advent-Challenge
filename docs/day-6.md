# День 6. Первый агент

## Задание

Реализовать простого агента, который принимает запрос пользователя, вызывает LLM через API и возвращает ответ в интерфейс.

## Что показать на видео

- Вкладку `Day 6 Agent`.
- Код `SimpleAgent` как отдельную сущность.
- API route, который обращается к агенту, а не напрямую к LLM.
- Ответ модели и блок `Agent trace`.

## Готово, если

- Логика запроса и ответа инкапсулирована в `SimpleAgent`.
- UI показывает ответ, метрики и шаги агента: input, messages, LLM call, output.
